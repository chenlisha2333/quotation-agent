# 需求增量：自然语言问答、Word 报价单与可选容器运行

版本：v0.3.0；日期：2026-10-21。本文补充现有 PRD，不改变既有施耐德品牌、人民币、成本价乘 1.2 的**草稿**规则及三角色审批。

## 业务目标与用户

技术、采购、商务人员可以在现有网页输入自然语言，收到关于当前任务状态和操作的回答。采购、商务能下载内部 Word 草稿；商务完成发布后能下载客户 Word 报价单。Excel 继续可用。初学者可本机直接运行；需要可复制环境时可选 Docker Compose。

## 功能与验收

| 编号 | 需求 | 验收标准 |
|---|---|---|
| NL-01 | 网页有提问输入框和 AI 回复区 | 提交后显示文字答复、模型错误或未配置提示；切换任务时清空本页对话 |
| NL-02 | 模型只读当前任务摘要 | `/assistant/chat` 不修改任务版本；仅发送当前令牌角色能看到的字段，最多 30 项、6 条历史，每条 1000 字 |
| NL-03 | 模型不控制报价 | AI 不能调用补价、审批或发布；无依据的产品参数、供应商价、CAD 尺寸应回答未知；金额由后端规则决定 |
| EX-01 | 内部草稿 Word | 完成且价格齐全的任务，采购/商务可下载含成本、规则、来源、总额的 `.docx` |
| EX-02 | 客户报价 Word | 商务完成三阶段审批并发布后，下载从冻结版本生成的 `.docx`；不含成本、加价率和内部备注 |
| EX-03 | Excel 兼容 | `/export` 缺省仍为 `.xlsx`；`file_type` 可选 `xlsx`/`docx`；金额一致 |
| DEP-01 | 可选容器启动 | `Dockerfile` 和 `compose.yaml` 提供单服务、本机端口、数据卷和健康检查；本地 Python 运行仍可用 |

## 数据流与边界

网页提问 → FastAPI 验证令牌 → 从 SQLite 读任务 → 复用角色过滤 → 提取受限摘要 → Responses API → 页面显示。模型文本仅作为解释，不回写 SQLite。网页导出请求 → FastAPI 检查角色、报价完成状态及审批发布状态 → Excel 或 Word 导出器 → 下载文件。客户版总是读取冻结快照。

页面展示模型回答时使用 `textContent`，不将回答当 HTML 执行。密钥只放环境变量；默认模型地址为官方 HTTPS API。使用其他兼容服务时，管理员需自行确认数据处理政策。涉及真实客户、成本与商业资料前，应评估是否允许发送相应角色可见摘要给模型；本版没有对模型输出作事实保证或自动审批。

## 已知未决与非目标

真实供应商人民币价格、完整施耐德选型、CAD 图纸、税率、有效期、企业模板与正式身份系统仍需业务确认。本版不做自然语言自动改价、语音、多模型路由、RAG 知识库、自动生成 CAD、自动发布或公网部署。当前 Docker 配置是本地演示方案；多用户生产部署需重新评估 SQLite、身份、密钥与备份。
