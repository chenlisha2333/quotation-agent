# 19 合成二维安装板布局与 DXF 确定性原型

## 业务目标：先把约束和校验跑通

Text-to-CAD 不能替项目猜柜体、元件尺寸或工程间距。当前先用完全虚构的安装板、元器件外形和禁布区，验证一条可重复的确定性基线：读取结构化规格、按固定顺序排布、独立复核 BOM 与几何，再输出待审核的二维 DXF 子集。

本模块不是企业柜型，不使用施耐德产品尺寸，不对应报价任务，也不能用于设计、制造或生产。所有输入被限制为 `data_class=synthetic`。

## 本轮实现范围

- 一块虚构 600×400 mm 的二维安装板；
- 5 种虚构元器件和矩形外形；
- 一块矩形禁布区、统一边缘净空和最小间距；
- 固定 BOM 顺序的可重复横向排布；
- BOM 数量、型号/外形、边界、禁布区、碰撞和间距校验；
- 校验失败时阻止 DXF 输出；
- 生成只含板框、禁布区、元件框和 ASCII ID 标签的 DXF 子集，并重新读取线段/标签，与布局逐项比对。
- 同时输出 sidecar 清单，记录规格/DXF 哈希、生成器 ID、校验状态和“未审核/不可用于工程”的标记。

当前没有安装专用 CAD Python 包，也没有在真实 CAD 软件中打开生成文件。因此“DXF 检查通过”指本模块识别的子集结构和几何坐标与输入布局一致，不是 AutoCAD、LibreCAD 或工程兼容性验收。清单的哈希能发现文件变化，不能防止有权写入同一目录的人同时替换 DXF 和清单。

## 代码路径

1. `PanelDesignSpec` 只允许 `synthetic` 数据，限制尺寸、元件种类/总量、ID 字符集和禁布区边界；这些约束控制演示的输入范围，不是公司工程规范。
2. `generate_layout()` 按 BOM 顺序采用横向货架式排布，遇到右边界就换行，避开禁布区及其间距。相同输入会产生相同坐标；它不优化散热、走线、维护空间或电气距离。
3. `validate_layout()` 独立比对预期数量和每个 placement，检查外形来源是否与规格一致、是否越出有效边界、是否压入禁布区，以及任意两个元件是否碰撞或小于给定间距。
4. `render_dxf()` 只有在 `validate_layout()` 返回空错误时才生成 ASCII DXF。DXF 中只保存矩形轮廓与由 item ID/序号组成的标签，不包含孔、接线或工程注释。
5. `dxf_entity_types()` 检查本项目支持的 LINE/TEXT 子集、基本区段、毫米单位标记、图层引用和数值字段；`validate_dxf_matches_layout()` 再比对读回的线段与标签坐标。它们不是通用 DXF 解析器。
6. `build_artifact_manifest()` 对输入规格和生成 DXF 计算 SHA-256，基于两者摘要生成内容寻址的 artifact ID，并将审核状态固定为 `not_reviewed`。`write_artifact_manifest()` 将 JSON 写入同目录临时文件后原子替换；`verify_artifact_manifest()` 后续可检测规格或 DXF 内容是否变化。当前没有把原始输入快照复制到产物目录或数据库。

## 运行和测试

在项目根目录运行：

```bash
.venv/bin/python -m pytest -q -p no:cacheprovider tests/test_cad2d.py
.venv/bin/python -m app.cad2d --output data/cad/synthetic_layout.dxf
```

命令会将运行产物和同名 `.manifest.json` 清单写到 Git 忽略的 `data/cad/` 下，并输出 `engineering_use_approved=false`。也可以通过 `--manifest` 指定 sidecar 清单位置。当前定向测试覆盖确定性、数量、边界、碰撞、禁布区、布局失败拒绝导出、DXF 格式/几何校验、DXF 事后篡改检测、清单哈希变化检测，以及阻止清单覆盖输入或 DXF。

## 还缺的工程输入与实现

需要电气/结构工程师提供并批准柜型及板面尺寸、安装孔、组件外形和安装方向、净空/间距、禁布区、真实 BOM 关联和已批准布局。其后还需把报价 BOM 快照、产品主数据版本、CAD 规则版本与产物哈希持久关联，实际归档输入快照，增加目标 CAD 软件验证、预览和工程师反馈流程。Text-to-CAD 要等这条确定性基线与同一校验器可用后再评测。

## 面试可能问

**这算 CAD 自动设计吗？** 不是。它是合成二维矩形布局与 DXF 子集生成原型；没有真实电气尺寸、孔位、接线或工程审批。

**为什么不让模型直接给坐标？** 第一版确定性基线用于验证输入契约和硬约束校验；有了它，才能对比模型布局的失败类别，并确保模型不能越过几何校验。

**间距检查能证明什么？** 只证明矩形几何按给定的合成最小间距计算，没有证明电气安全、散热、可维护性或可制造性。

## 小练习

1. 在临时副本中将某个合成元件宽度增大到超出有效板宽，说明校验器会在哪一步拒绝它。
2. 把一个 placement 移到禁布区内，运行定向测试并读出具体 BOM ID 和禁布区 ID 的报错。
