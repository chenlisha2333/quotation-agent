# 模块 10：施耐德询价表与 1.2 倍报价

更新日期：2026-10-21。先读本篇“业务目标”和“数据流”，再打开 `templates/施耐德询价表示例.xlsx` 对照代码。本篇的型号是**待技术核对的候选示例**，不是客户已经确认的选型；供应商单价为空。

## 1. 业务目标：为什么先做询价表

报价不能从一个模糊品名直接跳到销售金额。至少需要明确完整型号、数量、供应商成本价及其币种和凭证。这次新增一份可以直接被项目上传接口读取的示例表，列出三款有官方资料的施耐德产品。另一张表让采购回填正式人民币报价，第三张表记录初步尺寸，便于技术人员进一步核对。当前未取得这三款完整型号的有效人民币供应商采购报价，因此单价保持空白，上传后应进入人工确认。

用户指定的“加价是 1.2”按**售价 = 成本价 × 1.2**解释。例如成本 10.00 元、数量 2，单价 12.00 元，行金额 24.00 元。代码里的旧字段 `profit_rate` 是加价率，故对应 `0.20`，不是 `1.20`；20% 加价不等于 20% 毛利率。税、运费和正式企业签核仍未确定，所以规则 ID 使用 `draft-cost-times-1.2-v1`，客户发布仍受审批配置约束。

## 2. 核心技术及作用

| 技术 | 简单说法 | 专业定义及本项目作用 |
|---|---|---|
| Excel 工作表 | 一份文件中的不同页面 | `询价清单`是上传输入；`供应商报价回填`保存待采购填写的报价字段；`尺寸与资料`保存可追溯的工程参考。只有第一张表进入 `parse_excel`。 |
| `pandas.read_excel` | 把表格读成行列数据 | `app/parser.py::parse_excel`读取第一张表，再建立 `Product` 对象。首行必须是字段名。 |
| Pydantic | 检查每行字段是否合理 | `Product` 校验数量等结构；它不能证明电气型号适合客户项目。 |
| `Decimal` | 用十进制算钱 | `app/pricing.py`在单价处按分舍入，再乘数量，保存成本、加价率与规则 ID。 |
| FastAPI | 让页面能下载和上传模板 | `GET /templates/inquiry` 返回模板；`POST /upload` 固定使用加价率 `0.20`。 |

## 3. 为什么这样设计

询价清单把 `产品名称`、`型号`、`规格`、`品牌`、`数量`、`单位` 放在首行，使现有解析器直接可用；不在该工作表产品行下面写填写说明，因为解析器会把非空“产品名称”行当成产品。说明放在第二张表。采购报价留空，是为了区分**可核实的产品参数**与**尚未取得的交易价格**。尺寸只作初步 CAD 占位，不自动得出“柜内能装下”的结论。

修改默认加价率时同时更新规则 ID，并在上传端拒绝旧 `0.15` 参数，避免页面或旧调用方悄悄按 15% 生成新草稿。底层 `calculate_item_price` 仍允许显式传入其他 rate 供已有测试和内部计算使用，但会给它不同的 `draft-custom-...` 规则 ID，避免冒充当前 1.2 倍规则。

## 4. 与其他模块的关系和数据流

```text
询价清单 Excel → parse_excel → Product 列表 → 产品规则核对
  → 有完整合格人民币价格：查价/核查 → calculate_item_price
  → 没有合格价格：人工确认 → 采购录成本 → calculate_item_price
  → 内部草稿 → 技术/采购/商务审批 → 冻结客户版本
```

`供应商报价回填`不被程序自动当成成本数据库；采购人员必须核对报价凭证后，再按明细 ID 补价。`尺寸与资料`也不进入金额计算。默认币种仍由 `app/config.py::QUOTE_CURRENCY = "CNY"` 和模型约束控制。

## 5. 文件与关键函数

- `templates/施耐德询价表示例.xlsx`：三张工作表；下载入口为 `app/main.py::download_inquiry_template`。
- `app/parser.py::parse_excel`：从第一张表读取产品；列名经 `normalize_column_name` 标准化。
- `app/config.py`：`DEFAULT_PROFIT_RATE = Decimal("0.20")`、`PRICING_RULE_ID = "draft-cost-times-1.2-v1"`。
- `app/main.py::upload_excel`：拒绝非 `0.20` 的上传加价率，解析后调用工作流。
- `app/pricing.py::calculate_item_price`：计算单价与行金额并留下规则标识。
- `tests/test_inquiry_template.py`、`tests/test_money.py`、`tests/test_quote_journey.py`：检查模板、公式和完整接口链路。

## 6. 核心代码逐段解释

第一段，`parse_excel`执行 `pd.read_excel(file_path)`，默认取第一张表，然后把中文表头映射到模型字段。它要求 `name` 和 `quantity`，对非空产品名称逐行构建 `Product`。因此示例表的第一张工作表不能插入标题行；其他工作表只是辅助资料。

第二段，`upload_excel`里先核对 `profit_rate.is_finite()` 与 `profit_rate == DEFAULT_PROFIT_RATE`，否则返回 422。接着才保存、解析上传文件。页面不再让使用者修改加价率，避免界面与 API 行为矛盾。接口保留旧字段名是为了兼容既有调用约定。

第三段，`calculate_item_price`先把输入变成 `Decimal` 并检查范围；有成本时计算 `(cost * (1 + rate) * discount).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)`，再以舍入后的单价乘数量。默认 `rate=0.20`、`discount=1`，即成本乘 1.2。它还把成本、rate、discount、舍入方式与规则 ID 存进 `QuotationItem`，便于日后追溯。缺成本或成本为零时返回待人工确认项，不能把零当作真实采购价。

第四段，`pricing_rule_id`在参数等于默认时为 `draft-cost-times-1.2-v1`，显式使用其他 rate/discount 时是 `draft-custom-...`。这使商务审批的 `QUOTE_APPROVED_RULE_ID` 闸门能识别实际计算规则。即使技术测试设置同名环境变量，也不代表企业已经完成签核。

## 7. 必须掌握的 Python 基础

**必须掌握**：函数默认参数；`Decimal("0.20")`与二进制 `float` 的差别；`if` 条件；`None` 表示缺失而不是零；`list[Product]` 如何保存多行；`Path` 指向文件；Pydantic 模型如何校验数量。阅读 `test_default_price_uses_cost_times_1_point_2` 时，先手算 `10.01 × 1.2 = 12.012`，按分舍入为 12.01，再乘 2 得 24.02。

## 9. 常见错误与排查

- **上传把说明行也当产品**：检查第一张表 `产品名称` 列是否有说明文字；示例表已将说明移至第二张表。
- **返回 422“固定为成本价 × 1.2”**：调用方还发送了旧 `profit_rate=0.15`；去掉该字段或传 `0.20`。
- **三行都要人工补价**：这是正常行为。当前表没有采购成本，官方产品页的规格/尺寸不能代替正式人民币供应商报价。
- **尺寸放入 CAD 后装不下**：产品外形长宽深之外，还需安装孔位、端子及线缆空间、散热、维护间距和柜体/安装板尺寸；请从最新产品图纸与工程师方案核对。

## 10. 官方资料、价格线索与面试问题

官方产品资料：[A9F77216](https://eshop.se.com/eg/acti9-ic60n-2p-c-16a-mcb-a9f77216.html) 给出 36 × 85 × 78.5 mm；[LC1D09M7](https://www.clipsal.com/products/industrial/tesys/contactor-3p3-no-ac-3-ac-3e-0-to-440v-9a-220vac-50-60hz-coil-lc1d09m7?itemno=LC1D09M7)及其[施耐德尺寸图 PDF](https://iportal.se.com/Contents/docs/SQD-LC1D09M7.PDF)给出 45 × 77 × 86 mm，图纸还标出附件对深度和最小电气间距的影响；[XB4BA31 产品资料](https://www.se.com/be/en/product/XB4BA31/push-button-metal-harmony-xb4-flush-green-22mm-spring-return-unmarked-1no/)及[官方商城尺寸页](https://eshop.se.com/sg/push-button-metal-harmony-xb4-flush-green-22mm-spring-return-unmarked-1no-xb4ba31.html)给出面板开孔约 Ø22.5 mm、外形约 30 × 47 × 52 mm。尺寸表按宽 W、高 H、深 D 记录；具体安装方式与接线净空仍须核对最新图纸。采购询价入口可从[施耐德中国官网](https://www.se.com/cn/zh/)联系官方或授权渠道。[RS 中国的 XB4BA31 页面](https://www.rsonline.cn/web/p/push-button-switches/3308638)提供人民币参考价与询价联系线索，但检索快照和打开页面的参考价不同，且页面标注缺货，因此未写入采购确认单价。网上历史报价、其他币种价格和近似型号价格都不能冒充这三个完整型号的当前人民币采购价。

面试可能问：**为什么不能把供应商页的标价直接作为成本？** 因为必须核对完整型号、人民币、税、数量阶梯、交期、有效期和供应商凭证；现有价格准入不接受没有这些依据的数据。**为什么 20% 加价不是 20% 毛利？** 成本 100、售价 120 时，加价率是 `(120-100)/100 = 20%`，毛利率是 `(120-100)/120 ≈ 16.67%`。**为什么单价先舍入？** 项目当前规则这样定义并在测试中锁定；企业可选择不同规则，但须换版本并重新审批。
